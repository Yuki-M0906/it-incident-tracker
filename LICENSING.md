# Licensing and scope of this publication

This repository contains **design documentation** — architecture, data model, security
model and engineering notes written from an internal tool — plus **short, rewritten code
excerpts** that illustrate those designs. It does not contain the tool's source files,
sample data, manuals or anything identifying the organisation that operates it.

- The documents are published for reference and discussion. No licence is granted to the
  underlying software, which remains internal. The excerpts are illustrative; you may
  reuse the ideas, and the snippets are too small to be meaningfully licensed either way.
- Organisation names, personal names, e-mail addresses, directory structure, site names,
  address plans and identifier prefixes have been removed or generalised. If you believe
  something identifying remains, please open an issue and it will be removed.
- No warranty. The designs describe choices that fit one small team; they are not
  recommendations for every environment.
